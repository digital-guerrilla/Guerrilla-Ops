# Guerrilla Ops user guides

These guides expand on the quick introduction in the [project README](../../README.md). Start with the topic that matches the job you need to do.

| Guide | Use it to |

| [3. Asset View](03-asset-view.md) | Inspect components, relationships, floor plans, coordinate views, and asset details |
| [4. Document View](04-document-view.md) | Find, open, create, and maintain manuals, drawings, certificates, and links |

| [9. Plan viewer](09-plan-viewer.md) | Review floor SVGs, select rooms, navigate plans, and replace drawings |
